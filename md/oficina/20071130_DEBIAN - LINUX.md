# DEBIAN - LINUX

A comunidade que forma o [Projeto Debian](http://www.fr.debian.org/) tem por objectivo criar um [S.O. livre](http://www.fr.debian.org/intro/free).

Este sistema operacional chama-se [Debian GNU/Linux](http://www.fr.debian.org/intro/about), ou simplesmente [Debian](http://www.fr.debian.org/releases/stable/).

As ferramentas que formam o S.O. surgem do P[rojeto GNU](http://www.gnu.org/home.pt.html), disponiveis como [software livre](http://www.fsf.org/).

O [nucleo](http://www.kernel.org/) do sistema operativo conhecido por [LINUX](http://www.linux.org/), foi criado por [Linus Torvalds](http://www.cs.helsinki.fi/u/torvalds/).

Para além dos criadores, existem [comunidades de utilizadores](http://www.debianpt.org/), também em Portugal.

Principais arquivos de software para linux :

- [linux](ftp://ftp.linux.pt/)
- [gnu](ftp://prep.ai.mit.edu/)
- [debian](ftp://ftp.fr.debian.org/)
- [kernel](ftp://ftp.kernel.org/)
- [sistema X](ftp://ftp.x.org/)
- [gnome](ftp://ftp.gnome.org/)
- [gimp](ftp://ftp.gimp.org/)
- [blender](ftp://ftp.blender.org/)
